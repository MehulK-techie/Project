# LensCraft

LensCraft is a clean, minimal image discovery search application built with plain HTML, CSS, and modern CSS Grid.

### Original Features & Design Decisions
1. **Category Chips:** Included quick-search suggestion buttons under the search bar so users can quickly explore common image topics with a single click.
2. **Explicit Empty State:** Designed a visible empty-state message when the user lands on the page to provide immediate direction before any search is executed.
3. **Slate & Mint Theme:** Configured a dark slate background with vibrant mint green accents to establish a unique identity distinct from template defaults.
